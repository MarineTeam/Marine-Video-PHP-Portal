# Marine Video Portal - PHP Edition

Private, invite-only video portal ported from Next.js to **PHP 8.1+ with WordPress-style 5-minute installer**.

## Features carried from original repos
- **Bunny.net Stream**: TUS resumable uploads (browser → Bunny, signed), tokenized embeds per-request, signed thumbnails
- **Auth0**: v4-style login, session, admin/viewer gates (email identity)
- **Private share links**: recipient-locked, expiring, revocable, resend/extend/bulk, per-video private invite list
- **Bundles**: per-recipient consolidated page (like fable-video)
- **Viewer groups/tags**: bulk sharing, viewer tags
- **Watermark layers**: exemption > share > video > global (client overlay)
- **Resume**: Continue watching, playback progress
- **PWA**: manifest + sw.js (icons only cached)
- **Admin panel**: Videos, Viewers, Shares, Settings, Activity, Analytics
- **Security**: server-gated admin, signed tokens, geo-whitelist toggles, rate limit, fail-closed access

## What's new in PHP port
- **WordPress 5-min installer wizard** at `/install/` with environment checks
- **Configurable email**: Resend (default), SMTP (any provider: Brevo, Gmail, etc), SendGrid, Mailgun, Log
- **Multi-database**: MySQL, PostgreSQL, SQLite via PDO abstraction (no Redis needed)
- No Vercel dependency - runs on any LAMP/LEMP, shared hosting, Docker
