# Configuration Guide

Config lives in `config.php` (generated by installer, never committed). Example at `config/config.example.php`.

## Multi-Database
Change `database.driver`:
```php
'database'=>['driver'=>'pgsql', 'pgsql'=>[...]] // or mysql, sqlite
```
PDO abstraction handles queries. Migrations in `install/migrations.sql` are MySQL-first but installer auto-adjusts for SQLite (creates file) and pgsql (uses same DDL, works).

## Email - Switchable Drivers
In `config.php`:
```php
'email'=>[
  'driver'=>'smtp', // resend | smtp | sendgrid | mailgun | log
  'from'=>'Portal <videos@yourdomain.com>',
  'resend'=>['api_key'=>'re_xxx'],
  'smtp'=>['host'=>'smtp.brevo.com','port'=>587,'username'=>'...','password'=>'...','encryption'=>'tls'],
  'sendgrid'=>['api_key'=>'SG.xxx'],
  'mailgun'=>['domain'=>'mg.yourdomain.com','api_key'=>'key-xxx']
]
```
Interface: `MarinePortal\Email\EmailInterface`. Add new driver by implementing `send()` and registering in `EmailManager::driver()`.

- Resend: recommended, same as original Next.js app
- SMTP: universal fallback - any provider
- SendGrid/Mailgun: API drivers
- Log: writes to `storage/logs/email.log` for dev

## Auth0
Keep sign-ups disabled. Admin list via `admin_emails` array. Gate secret used for share magic links (like original GATE_SECRET).

## Bunny.net
- Enable Token Authentication in Bunny dashboard Security tab
- Note CDN hostname for thumbnails (vz-xxx.b-cdn.net)
- If pull zone has Token Auth enabled, set cdn_token_key

## Security
- Geo whitelists: set `security.geo_whitelist` = "US,CA" and toggle in admin Settings (off by default, like original)
- Admin bypass list for traveling admins

## Push (VAPID)
Generate with `npx web-push generate-vapid-keys` and set in config vapid keys to enable Notify button + broadcasts.
